# SOYJAK PARTY ENHANCED

**A userscript for improving the [Soyjak.party](https://soyjak.st) experience.**

## Installation

Install [Violentmonkey](https://violentmonkey.github.io/) or any other userscript manager, then [click here to install SPE](https://github.com/hoo-d/soyjakparty-enhanced/blob/main/soyjakparty-enhanced.user.js?raw=true).

## Features

* Everything from [the original repo](https://github.com/extteen/soyjakparty-enhanced)
* Not having to install an extension for this
